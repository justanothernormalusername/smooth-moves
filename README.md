# Smooth Moves

## Play it here!!
https://justanothernormalusername.itch.io/smooth-moves

## Description:
You're just a little guy making a big smoothie in an even bigger kitchen. Use your pen's magical powers to move all the ingredients into the blender! This game was created for the [Jame Gam game jam](https://itch.io/jam/jame-gam-game-jam) by Hack Club. I wanted to practice asset creation, so there are fewer features, but I hand-drew all the assets!

## Controls:
- AD - Move left/right
- Space - Jump
- Hold left-click - Draw physical lines

## AI Disclosure:
Generative AI was used for debugging and assisted with the line-drawing feature. No assets were generated with AI.
